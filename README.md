Deploying to the Cloud
While there are many ways to deploy a website to the cloud, we'll use a really simple platform called static.app.

Here's how it works:

Make sure you have a file index.html in your project folder
Create a ZIP archive using your project folder
Visit https://static.app and upload the ZIP file
Create an account by providing email, name and password
Verify your account using the link sent over email
The website will be deployed as a subdomain of static.app


 Sending Form Responses Over Email
			We can use the platform https://formbold.com to sent form response over email:
			
			Sign up on formbold.com
			
			Create a new form
			
			Open the form settings
			
			From the integration tag, copy the form URL
			
			Add the form URL with a POST action in your form
			
			Follow the usage guidelines for "Form with file upload" to set other tags appropriately
			
			Reload your web page, make a sample submission, and verify that the response was recroded
